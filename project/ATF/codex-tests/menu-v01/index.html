Codex-tests · Menu v01

Catálogo de menus — desktop e mobile

6 conceitos, cada um com versão desktop e mobile lado a lado. Três ficam dentro do universo visual atual da ATF (preto/branco/dourado, tipografia pesada, sem cantos arredondados); um retoma a pílula flutuante do teste homepage-v03-freeform-taste; dois puxam de padrões de fora (mega-menu com produtos, barra de abas mobile) pra dar variedade real de discussão com o Ronald. Removido o menu lateral fixo — ocupar tela de desktop de forma permanente não é algo que entraria em produção. Clique nos gatilhos de menu pra ver a interação de verdade.
