# ATF — Testes de blocos de produto

Protótipos exploratórios de HTML/CSS/JS testando diferentes formas de apresentar os produtos
e blocos de conteúdo da ATF na home do site. Não substituem o design aprovado do Ronald no
Figma — servem como referência e ponto de partida para discussão.

Abra `index.html` para o menu geral, com um resumo de cada rodada e link para abrir cada uma.

## Rodadas

- **v01** — Estrutura: índice editorial, grade por pilar, carrossel horizontal.
- **v02** — Conteúdo: editorial em tela cheia e índice com preview interativo, primeiros
  componentes reais do Design System.
- **v03** — Mural lúdico: cards inclinados de tamanhos variados, vídeos de ilustração reais
  das Credenciais.
- **v04** — Tela cheia + paralaxe: texto acima, vídeo grande abaixo, paralaxe alternando
  sentido a cada bloco.
- **v05** — Overlay em tela cheia + mosaico: vídeo cobrindo a tela com texto sobre cartão
  translúcido, e um layout em mosaico (cheio / dois lado a lado / cheio / ...).
- **v06** — Catálogo de blocos: 17 padrões reaproveitáveis (texto puro, imagem de fundo,
  imagem ao lado, marquee, grade assimétrica, scroll storytelling, stats, etc.), usando fotos
  reais em vez de vídeo para deixar o tamanho de cada componente mais claro.

## Assets

Os arquivos em `assets/` são cópias de material já existente da ATF (vídeos e fotos das
Credenciais, ilustrações e logos), incluídas aqui apenas para os testes funcionarem de forma
autônoma. O material completo (Credenciais, Design System, Brand Guidelines) vive no projeto
principal e não está neste repositório.
