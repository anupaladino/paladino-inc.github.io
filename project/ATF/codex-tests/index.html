Biblioteca de componentes — índice

Doze rodadas de testes exploratórios de componentes e páginas pro site da ATF: navegação (menu), seis rounds de blocos de conteúdo, footer, uma galeria, os 3 componentes finais fechados com o Ronald, e duas páginas institucionais completas — estrutura, tom e uso de assets reais das Credenciais. Nenhuma substitui o trabalho do Ronald no Figma; servem como referência e ponto de partida, migradas pra lá conforme validadas.
